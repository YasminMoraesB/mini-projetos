# 🌟 FAQ Soraka - Guia Explicativo

Um mini projeto desenvolvido com **HTML, CSS e JavaScript** que apresenta um guia interativo da campeã **Soraka**, de League of Legends, utilizando um componente de **Accordion (FAQ)**.

O objetivo do projeto foi praticar manipulação do DOM, responsividade e criação de interfaces simples utilizando apenas tecnologias web puras.

## 🧠 O que pratiquei

Durante esse projeto pratiquei diversos conceitos importantes do desenvolvimento Front-end, como:

* Seleção de elementos com `querySelector()`
* Manipulação de classes utilizando `classList.toggle()`
* Eventos de clique (`addEventListener`)
* Estruturação semântica com HTML
* Flexbox
* Media Queries
* Transições e animações com CSS
* Organização de arquivos (HTML, CSS e JavaScript separados)
