# Gerador de Cores Aleatórias

Um gerador simples que muda a cor de fundo da página e mostra o código hexadecimal.

## Como funciona

- Clique no botão **"Cor"**
- A cor de fundo da página muda aleatoriamente
- O código hexadecimal da cor aparece na tela

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Arquivos do projeto

- `index.html` - Estrutura da página
- `style.css` - Estilos e animações
- `script.js` - Lógica de geração de cores

## Detalhes

- O CSS tem um efeito de expansão circular no botão
- As cores são geradas aleatoriamente no formato hexadecimal (#000000 até #FFFFFF)
- Ao clicar, o código da cor é exibido na tela
