# Contador de Cliques

Um contador de cliques simples, com intenção de praticar **addEventListener** e **setInterval**.

## Como funciona

- Clique no botão **"Cliques"** para aumentar o contador
- **Segure o botão** pressionado para contar rapidamente
- Clique em **"Resetar"** para zerar a contagem

## Tecnologias usadas

- HTML
- CSS  
- JavaScript

## Arquivos do projeto

- `index.html` - Estrutura da página
- `style.css` - Estilos e cores
- `script.js` - Lógica do contador
- `background.png` - Imagem de fundo
