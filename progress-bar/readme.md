# Barra de Progresso
Um site simples contendo um texto e uma barra de progresso que conta através do scroll da tela.

## 🎯 Objetivo de Estudos

Este projeto foi desenvolvido para praticar:
- Manipulação do DOM com JavaScript
- Eventos de scroll
- Uso de `scroll` para rolagem da tela.
- Estilização com CSS (hover, transições, responsividade)
- Layout com imagens sobrepostas (fixed)

## Como funciona

- Um texto simples com uma borda e uma barra acima.
- Ao scrollar a tela para ler o conteúdo.
- O progresso aumenta até chegar o 100%
- Subindo a tela o progresso "retorna" ao ponto inicial..

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Arquivos do projeto

- `index.html` - Estrutura do perfil
- `style.css` - Estilos e responsividade
- `script.js` - Lógica da barra
