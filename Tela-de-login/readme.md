## ✨ Funcionalidades

- 🍃 Layout dividido em duas colunas
- 👤 Campo para nome
- 📧 Campo para e-mail
- 🔒 Campo para senha
- ✅ Validação dos campos utilizando JavaScript
- ⚠️ Exibição de mensagens de erro abaixo dos inputs
- 🎨 Efeitos de hover em botões e ícones
- 📱 Interface limpa e moderna

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Bootstrap Icons

---

## ✔️ Validações implementadas

O formulário verifica:

- Nome obrigatório
- E-mail válido (contendo "@" e ".")
- Senha com no mínimo 6 caracteres

Caso algum campo esteja incorreto, uma mensagem de erro é exibida abaixo do respectivo input.

Quando todos os campos são preenchidos corretamente, é exibido um alerta informando o sucesso do envio.
