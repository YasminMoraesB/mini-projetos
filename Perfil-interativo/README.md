# Perfil Interativo

Um card de perfil estilo redes sociais com botão "Follow" interativo.

## 🎯 Objetivo de Estudos

Este projeto foi desenvolvido para praticar:
- Manipulação do DOM com JavaScript
- Eventos de clique e mudanças de estado
- Uso de `setInterval` para contagem crescente
- Estilização com CSS (hover, transições, responsividade)
- Layout com imagens sobrepostas (position relative/absolute)

## Como funciona

- O card exibe um perfil com foto, nome, username e biografia
- Ao clicar em **"Follow me"**, o botão muda para **"Following"**
- O contador de seguidores começa a aumentar automaticamente
- Clicando novamente, o botão volta para "Follow" e o contador zera

## Tecnologias usadas

- HTML
- CSS (com media queries para responsividade)
- JavaScript

## Arquivos do projeto

- `index.html` - Estrutura do perfil
- `style.css` - Estilos e responsividade
- `script.js` - Lógica do botão e contador

## Detalhes do projeto

- O contador soma 1 a cada 100ms enquanto o botão está em "Following"
- Design responsivo para diferentes tamanhos de tela
- Efeitos hover nos botões e na seção "About"
- Efeito de brilho (box-shadow) na foto do perfil
