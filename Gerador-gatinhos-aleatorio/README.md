# 🐾 Gerador de Gatos Aleatórios

Uma aplicação que gera imagens aleatórias de gatos utilizando uma API pública, com uma interface inspirada em cores suaves e estética kawaii.

## ✨ Sobre o projeto

Este projeto foi desenvolvido para praticar consumo de APIs utilizando JavaScript puro (`fetch API`), além de treinar estilização com CSS e construção de interfaces criativas.

A aplicação consome imagens aleatórias da The Cat API e exibe um novo gatinho sempre que o usuário clicar no botão.
